# Desktop 2.0 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** Ship Desktop 2.0 with bounded recovery from incomplete installations, reliable queued-message continuation after cancellation, matched Windows title-bar colors, a livelier low-cost startup whale, and a disabled-by-default community entry for `dsh-taffy-pet`.

**Architecture:** A shared runtime-integrity module defines release and launch-time critical files, and the controller refuses to spawn when preflight fails. A host-only Cordis bundle uses public agent and tool hooks to re-arm stranded FIFO queues after cancellation and normalize the known object-string abort error. The shell keeps native caption controls while matching their solid theme colors in injected CSS. Extension Dock exposes fixed third-party metadata and opens only an allowlisted author repository; third-party code and character assets remain outside the installer.

**Tech Stack:** Electron 43, Node.js ESM and Node test runner, HTML/CSS, Canvas 2D, Playwright, electron-builder.
