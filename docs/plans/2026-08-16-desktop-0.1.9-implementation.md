# Desktop 0.1.9 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task.

**Goal:** Ship Desktop 0.1.9 with reliable conversation copying, background application updates, a glass update surface, a simplified particle-whale startup screen, and the official Hindsight coding-agent integration included by default.

**Architecture:** Electron owns clipboard permissions and the complete application-update state machine. A narrow preload/IPC bridge publishes update state to an injected desktop-only renderer surface, while the Web UI update trigger delegates to that bridge when present. The startup whale is a local Canvas 2D effect with no network assets and no runtime presence after navigation.

**Tech Stack:** Electron 43, electron-updater, Node test runner, React 18/Vitest, HTML/CSS, Canvas 2D, Playwright.
