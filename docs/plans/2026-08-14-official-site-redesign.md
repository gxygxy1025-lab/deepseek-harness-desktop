# DeepSeek Harness Desktop 官网复刻设计

## 目标

以 DeepSeek Harness 官方官网为视觉基准，重建社区桌面版官网。页面需要在第一眼呈现相同的品牌气质，同时把 Windows 下载入口与桌面版独有能力放在更高优先级。

## 复刻范围

- 深色页面、模糊蓝灰英雄背景与半透明胶囊导航。
- 官方站接近的内容宽度、字号比例、圆角、卡片密度和大段留白。
- 首屏左侧说明、右侧终端卡片；三列能力卡；交替图文功能区；双列安装卡；社区结尾。
- 克制的淡入动画、固定导航与移动端响应式布局。

## 桌面版特色

- 下载 Windows x64 按钮在首屏和固定导航中保持可见。
- 使用真实截图介绍原版 Web Surface、桌面生命周期、扩展坞、任务看板、主题与手机远程。
- 主题预览可切换，安装与源码命令可复制，版本与安装包大小从 GitHub Release 自动同步。
- 保留“社区版”标识和权利归属说明，避免与官方发行版混淆。

## 验证

在 1440 x 900 与 390 x 844 视口下检查首屏、功能区、主题切换、复制交互、下载链接、横向溢出和控制台错误。部署后验证 GitHub Pages 页面、样式和主要图片均返回 HTTP 200。
