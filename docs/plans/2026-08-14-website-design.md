# DeepSeek Harness Desktop 官网设计

## 目标

为开源桌面端项目建立一个下载优先、可由 GitHub Pages 持续部署的中文官网。首屏必须让访问者在数秒内理解产品、看到真实界面并下载 Windows x64 安装包。

## 方向

页面采用深海蓝黑色、细网格、青色高光和大字号衬线标题，延续 DeepSeek Harness 官方页面的克制开发者气质，同时使用桌面版现有启动界面中的编辑化构图建立独立识别。所有产品图均来自仓库真实截图，不使用概念图冒充功能。

## 信息结构

1. 首屏：社区桌面版定位、Windows 下载、GitHub 入口、当前版本与安装包信息。
2. 产品证明：真实主界面大图及本地运行、原生生命周期、自动更新三个关键信号。
3. 功能介绍：桌面封装、扩展坞、任务看板、Git 图谱、文件预览与主题皮肤。
4. 跨端能力：手机远程控制的真实截图。
5. 最终转化：重复下载入口、校验值入口和开源仓库入口。

## 技术与发布

官网为无构建依赖的静态 HTML、CSS 和 JavaScript。JavaScript 通过 GitHub Releases API 读取最新版本和 EXE 资产；请求失败时保留 0.1.3 的可用直链。GitHub Actions 上传 `website/` 并部署到 GitHub Pages。页面需通过桌面和移动视口检查、链接检查及基础无障碍检查。
