# DeepSeek Harness Desktop 1.0.6

This release fixes visible Windows terminal windows during DSH plugin search/install by hiding the official Runtime's general subprocess launcher. It also provides the Windows x64 Desktop core with automatic GitHub Release updates, startup diagnostics, system tray support, and an isolated desktop profile.

The repository no longer ships the legacy plugin market, third-party extension collection, QQ Bot, skin center, task board, community window, or promotional website.
