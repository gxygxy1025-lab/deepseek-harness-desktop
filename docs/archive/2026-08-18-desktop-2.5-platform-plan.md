# Desktop 2.5 Compatibility, Sharing, and System Integration Plan

> Implementation record for the current worktree. No commits, pushes, pull requests, or releases are part of this plan.

**Goal:** Deliver Desktop 2.5.0 with a controlled DSH runtime adapter, candidate compatibility evidence, atomic multi-plugin and Preset transactions, clear post-install activation, Web-to-Desktop profile migration, safe deep links and file association, and bounded native notifications.

**Architecture:** Keep Electron as the lifecycle and security shell and retain the official DSH runtime as a child process. Wrap the proven 2.4 controller/profile implementation with a small capability-based provider; route package and portable-profile changes through one transaction coordinator; keep URL, file, and notification inputs behind typed Desktop Contract services and sender-surface checks.

**Tech stack:** Electron 43, Node.js from the checked-in engine/package metadata, pnpm 11.22.0, official DSH 0.1.0-rc.6 packages, JavaScript modules, TypeScript Cordis bundles, node:test, Vitest, Playwright, electron-builder, and GitHub Actions.
