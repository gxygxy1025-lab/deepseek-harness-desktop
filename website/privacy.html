隐私政策

匿名统计只回答产品是否正常工作，不记录你用它做了什么。

最后更新：2026 年 8 月 19 日

本地优先 默认匿名统计 统计范围 明确不收集 处理与保留 联系维护者

默认开启，不提供应用内关闭开关

使用官方正式版即表示你已阅读本政策

DeepSeek Harness Desktop 官方正式版默认启用匿名产品统计。下载安装、启动或继续使用本软件，即表示你已经阅读、理解并在适用法律允许的范围内同意本政策所述的数据处理方式。

普通源码构建、开发构建、测试构建和 Fork 构建不包含官方统计端点，默认不会向官方统计服务发送数据。

本地优先

你的对话、提示词、AI 回复、API 密钥、账号配置、工作区、文件、插件配置和个人偏好保存在你的设备或你自行选择的服务中。桌面版不会为了产品统计而上传这些内容。

当你主动配置并调用模型服务、远程连接、QQ Bot 或其他第三方服务时，相关数据会按照你的操作发送给对应服务商；这不属于本政策所述的匿名产品统计。

统计范围

应用只会发送由固定枚举或有限区间组成的产品数据：

  • 软件版本、稳定或预发布通道、Windows 10/11 大类、中文/英文/其他语言大类；
  • 应用启动、运行时启动结果与耗时区间、固定类别的恢复操作；
  • 设置、扩展、社群、更新与帮助等主要桌面入口的打开次数；
  • 更新结果、扩展安装/更新/移除/启停的操作类型与成功或失败；
  • 一次应用会话的时长区间。
  • 官方网站安装包的版本、导航/首屏/终端卡片/安装区四类固定下载入口，以及按日聚合的两位国家代码。

应用和网站不发送客户端精确时间；统计服务仅使用请求到达时的 UTC 日期完成按日聚合。安装包仍由 GitHub 直接提供，地区统计表示下载点击而不是完整下载成功。

明确不收集的内容

不收集内容对话、提示词、AI 回复、会话标题、文件内容、文件名或路径
不收集凭据API Key、Token、Cookie、请求头、账号信息或配置
不收集身份IP 地址、User-Agent、机器码、硬件序列号或长期设备标识
不收集诊断原文插件名、模型名、原始错误、日志、堆栈或崩溃转储

网站下载统计不会保存省州、城市、精确位置、精确时区、Referrer 或原始下载请求。

匿名产品统计也不会读取或复用 DeepSeek Harness 自带的匿名用户标识与会话遥测记录，不用于广告、跨产品跟踪、用户画像、自动化决策或用户风控，也不会出售给第三方。

处理方式与保存期限

统计请求通过 HTTPS 发送，由 Cloudflare 网络接收。Cloudflare 会为提供网络服务而处理连接信息，但本项目的统计代码不会将 IP 地址、User-Agent 或请求头写入产品统计数据库。

服务端不会保存原始事件，而是在接收时直接写成桌面产品维度或“UTC 日期、两位国家代码、安装包版本、固定下载入口、数量”的按日汇总记录。数据库没有用户、安装或设备标识，无法构建个人事件历史。

按日汇总记录最长保留 365 天，之后自动删除。因为数据中没有用户标识，维护者无法按个人查询、导出或删除某个人的统计记录。

可靠性、安全与政策更新

客户端、网站和服务端都使用固定事件白名单、字段枚举、来源限制、批量与大小限制。网站通过异步 Beacon 上报下载点击，失败时直接丢弃，不会取消、替换或延迟 GitHub 安装包直链；桌面上报失败也不会阻止或延迟应用启动、使用、更新或退出。

本政策可能随产品功能、统计范围或服务商变化而更新。若未来计划加入能够识别或长期关联用户的新字段，项目会重新评估政策和产品交互；本政策不能被解释为允许收集上述明确排除的数据。

联系维护者

如对隐私政策或匿名产品统计有疑问，请通过 GitHub Issues 联系项目维护者。完整的可审查版本也保存在仓库根目录的 PRIVACY.md。
